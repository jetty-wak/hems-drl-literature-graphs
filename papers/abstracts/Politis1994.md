## Claims supported in thesis

- The statistical protocol therefore uses a paired, time-series-aware design: compared decision methods are evaluated on identical test days so that meteorological and tariff variation cancel within each pair, the primary hypothesis-testing outcome is daily operating cost (EUR/day) obtained by aggregating per-step costs, and uncertainty is reported using 95\% confidence intervals from a block bootstrap over daily observations (default block length 7 days)
